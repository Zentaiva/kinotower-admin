# Kinotower Admin

Учебная админ-панель для практики по веб-технологиям.

В окружении нет PHP и Composer, поэтому проект сделан как самодостаточное Node.js приложение без внешних зависимостей. По функциональности закрывает задания за 6 дней: миграции/сидинг имитируются JSON-хранилищем, есть авторизация администратора и CRUD-разделы.

## Запуск

```bash
npm start
```

Адрес: http://127.0.0.1:8000

## Доступ администратора

- Email: `admin@kinotower.local`
- Пароль: `password`

## Реализовано

- страны;
- жанры;
- фильмы с фильтрацией по стране и жанру, пагинацией;
- жанры выбранного фильма;
- пользователи с мягким удалением и восстановлением;
- отзывы с одобрением и удалением;
- рейтинги с удалением.
